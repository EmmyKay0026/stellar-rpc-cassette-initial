# Changelog

## 0.1.0 — 2026-10-01

Initial developer-ready release:

- deterministic JSON-RPC cassette recording and strict offline replay;
- sequential and strict matching modes with request-ID restoration;
- credential forwarding without cassette secret persistence;
- real Testnet fixtures for ledger, simulation, and paginated events;
- CLI commands for record, replay, inspect, and managed command wrapping;
- publishable CLI, core, and proxy npm packages.
